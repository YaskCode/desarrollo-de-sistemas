# Criterios de organización y procedencia

Referencias revisadas el 12 de noviembre de 2026:

- [Sistemas Inteligentes](https://github.com/YaskCode/sistemas-inteligentes): README y árbol docs; navegación por temas, sprints, laboratorios, recursos y rúbricas; separación entre programa y código estudiantil.
- [Ingeniería de Software y Bases de Datos](https://github.com/YaskCode/ing-sofware-y-base-datos): README y árbol docs; identidad institucional al inicio, tabla de evaluación, vínculos a documentos originales y a YaskCode-laboratory.

Se adoptan identidad textual, navegación Markdown, tablas de evaluación y separación de responsabilidades. Se adapta la organización a las siete carpetas solicitadas y seis temas de PP4. No se trasladan las duraciones, porcentajes, proyectos Wellness, licencias o tecnologías propias de las asignaturas de posgrado.

Los PDF son las fuentes académicas: programa para contenidos y evaluación; presentación para proyectos, entregables y entorno. Objetivos operativos, orientación bibliográfica, guías y criterios cualitativos se etiquetan como propuestas. No se incorporan escudos o logotipos nuevos.

[Observaciones documentales](observaciones.md) · [Inicio](../README.md)

La presentación general se mantiene una sola vez en presentaciones/, sin subcarpetas por unidad. Las seis unidades utilizan nombres descriptivos y el índice de proyectos se denomina proyectos-propuestos.md, conforme al árbol solicitado.
