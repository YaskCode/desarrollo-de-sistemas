# Unidad 6. Pruebas y Mantenimiento de Sistemas

## Contenidos del programa

- Tipos de pruebas: unitarias, integración, sistema y aceptación.
- Técnicas: caja negra y caja blanca.
- Herramientas de testing: pytest y pytest-django.
- Mantenimiento: correctivo, adaptativo y perfectivo.
- Gestión de cambios y versionamiento.
- Documentación técnica y para usuarios finales.

## Objetivo de aprendizaje propuesto

Verificar comportamientos y registrar defectos, cambios y mantenimiento.

## Trabajo de la unidad y evaluación

Corresponde a **E7 y E8**, según el [índice de ocho entregables](../../proyecto-integrador/entregables/README.md). Las fichas reúnen alcance, guía de elaboración, evidencias y comprobación previa. No se asignan tareas paralelas ni porcentajes internos.
