Mermaid no ofrece una notación DFD específica: un flowchart no sustituye automáticamente un DFD. Usar diagrams.net para representar y revisar procesos, flujos, almacenes y entidades externas con una convención explícita. Mermaid se mantiene para los tipos que sí soporta, como ER y estados.

NoSQL, Balsamiq, JUnit, Selenium y Postman se conservan como contenidos del programa; no se incorporan como dependencias obligatorias del proyecto Python. Véanse las [observaciones](../docs/observaciones.md).
