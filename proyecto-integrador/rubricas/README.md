# Rúbricas cualitativas propuestas

**Estado: propuesta complementaria pendiente de aprobación docente.** Las fuentes no incluyen una rúbrica con pesos. Esta matriz sirve para retroalimentación inicial; no calcula calificaciones ni añade criterios obligatorios. Los criterios concretos por entrega se encuentran en las [fichas E1–E8](../entregables/README.md).

| Evidencia | Consistente | En revisión | Insuficiente |
|---|---|---|---|
| E1: caracterización | Problema, objetivos, alcance y requisitos se corresponden | Hay ambigüedades localizadas | No puede identificarse el problema o alcance |
| E2: DFD | Flujos balanceados y niveles trazables | Diferencias puntuales entre niveles | Descomposición sin correspondencia |
| E3: diccionario DFD | Datos definidos y relacionados con el modelo | Faltan dominios o restricciones | Nombres sin definición verificable |
| E4: procesos | Reglas y decisiones explican cada proceso documentado | Existen excepciones sin resolver | Pasos no permiten determinar resultados |
| E5: entradas/salidas | Interfaz relacionada con requisitos y validaciones | Hay entradas o salidas ambiguas | No se reconoce el flujo de interacción |
| E6: BD | ER, tablas, SQL y diccionario son coherentes | Restricciones o normalización incompletas | SQL/modelo no representan el dominio |
| E7: implementación/pruebas | Flujo integrado y pruebas reproducibles | Fallos o cobertura pendiente identificados | No se reproduce el funcionamiento |
| E8: mantenimiento | Versiones, cambios y manuales corresponden al sistema | Documentación parcialmente desactualizada | No hay trazabilidad de cambios o uso |
| Proyecto final | Integración, demostración, CI y documentación concordantes | Integración con limitaciones declaradas | No se logra demostrar el flujo integrado |

No se define rúbrica de asistencia ni umbrales de participación: el mecanismo de registro y su aplicación quedan a decisión docente. Tampoco se asignan puntos por nivel ni pesos internos de sprint.
