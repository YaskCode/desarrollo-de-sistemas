# L3. Diccionario y decisiones

**Propuesta complementaria** · [Unidad 3](../unidades/unidad-03/README.md) · Apoya E3 y E4.

## Requisitos

DFD del laboratorio 2 y editor Markdown.

## Caso de práctica

Datos sintéticos de oferta: identificador, organización, descripción y estado.

## Procedimiento

1. Inventariar todos los flujos y almacenes del DFD.
2. Descomponer una estructura de datos en elementos con tipo, dominio y restricciones.
3. Elegir un proceso primitivo y registrar entradas, precondiciones, reglas, pasos y salidas.
4. Construir una tabla de decisión para una regla hipotética de aprobación, marcándola como supuesto.
5. Recorrer combinaciones de condiciones para localizar contradicciones o casos sin respuesta.

## Evidencia propuesta

Diccionario DFD y especificación de proceso con tabla de decisión.

## Comprobación y resultado esperado

Todos los nombres coinciden con el DFD; cada combinación relevante tiene una acción definida.

## Dificultades frecuentes

No confundir el almacén lógico del DFD con una tabla física SQL; revisar su trazabilidad.
