# L1. Caracterización y trazabilidad

**Propuesta complementaria** · [Unidad 1](../unidades/01-introduccion-si/README.md) · Apoya E1.

## Requisitos

Editor Markdown y ficha de un proyecto del índice.

## Caso de práctica

Usar un caso sintético: un estudiante consulta una oportunidad publicada y solicita participar.

## Procedimiento

1. Crear una tabla de actores, necesidades y límites del SI.
2. Escribir un requisito funcional para consultar oportunidades y otro para solicitar participación; agregar una restricción no funcional verificable.
3. Relacionar cada requisito con una regla de negocio e indicar su fuente o marcarla como supuesto pendiente de validación.
4. Comparar qué pasos se organizarían con Scrum y cuáles mediante un tablero Kanban.

## Evidencia propuesta

Documento Markdown con alcance y matriz actor–necesidad–requisito–regla.

## Comprobación y resultado esperado

Cada requisito tiene identificador, actor y resultado observable. Las suposiciones están señaladas.

## Dificultades frecuentes

Revisar con otro integrante si un requisito describe una solución técnica en lugar de una necesidad.
