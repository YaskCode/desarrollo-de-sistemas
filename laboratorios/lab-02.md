# L2. DFD y balance

**Propuesta complementaria** · [Unidad 2](../unidades/unidad-02/README.md) · Apoya E2.

## Requisitos

diagrams.net; caracterización E1 disponible.

## Caso de práctica

Caso sintético: empresa envía oferta, coordinación revisa y estudiante consulta.

## Procedimiento

1. Listar entradas, salidas, entidades externas y almacenes necesarios.
2. Dibujar el contexto y nombrar flujos de datos con sustantivos; evitar flechas que representen solo control.
3. Descomponer el proceso según la convención de nivel acordada; desarrollar al menos un proceso hasta nivel 2.
4. Crear una tabla que compare cada entrada/salida del proceso padre con las del hijo. Registrar discrepancias.
5. Exportar una vista legible y conservar el archivo editable.

## Evidencia propuesta

DFD editable, exportación y tabla de balance.

## Comprobación y resultado esperado

No hay flujo directo entre dos almacenes ni entidad externa y almacén. Las entradas/salidas entre niveles se corresponden.

## Dificultades frecuentes

Si faltan flujos en un nivel, corregir el modelo antes de completar el diccionario. Acordar contexto/nivel 0 con la docente.
