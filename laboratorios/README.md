Las prácticas se ejecutan en el repositorio o entorno del equipo. No se aloja aquí el código de sus aplicaciones. Las guías han sido revisadas documentalmente; no se afirma que se haya ejecutado una aplicación Django ni un servidor PostgreSQL durante esta implementación.
